# CampusConnect 🎓
### Campus Event Discovery & Registration Hub

CampusConnect is a web-based project designed to help university students discover campus events, explore activities, and access event registration features through a simple, user-friendly interface.

## About the Project

CampusConnect aims to make campus event information more accessible by bringing event details together in one place.

This project was developed as part of the **CSE326 – Web Development** course at Lovely Professional University.

## Features

- Home page with an introduction to CampusConnect
- Navigation bar with links to different sections
- About section explaining the platform
- Event listings and event-related information
- Responsive layout using HTML and CSS
- Simple and user-friendly interface

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality, where implemented
